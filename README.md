# 💻 Laptop Price Prediction using Machine Learning

This project predicts laptop prices based on specifications such as brand, RAM, storage, processor, GPU, and screen resolution using Machine Learning techniques.

## 🔍 Key Features
- Data Cleaning & Preprocessing
- Feature Engineering
- Model Training & Evaluation
- Prediction Pipeline

## 🛠 Tech Stack
Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

## 🎯 Objective
To help users understand pricing patterns and make informed laptop purchasing decisions.

## 🚀 How to Run
Open the Jupyter notebook and run all cells sequentially.

## 📊 Output
Trained regression model capable of predicting laptop prices accurately.
